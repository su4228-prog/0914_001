# 동네픽 최종 웹사이트

## 실행
VS Code에서 폴더를 열고 `index.html`을 Open with Live Server로 실행하세요.

## 배경 영상
`assets` 폴더 안에 기존 도시 영상을 아래 이름으로 넣어주세요.

`city-bg.mp4`

## 구성
- index.html
- style.css
- app.js
- data.js
- assets/city-bg.mp4

## 추천
성향 카드 + 계약유형 + 주택유형 + 선택 예산을 반영해 서울 25개 자치구 적합도를 계산합니다.


## 지도 파일
이번 버전은 외부 GitHub 지도 주소를 사용하지 않습니다.

`assets/seoul-districts.geojson`

파일을 웹사이트 내부에서 직접 읽어 지도 모양을 표시합니다.
D3.js CDN도 제거했기 때문에 지도 렌더링에 외부 라이브러리가 필요하지 않습니다.

※ index.html 파일을 더블클릭(file://)으로 열면 브라우저 보안상 로컬 GeoJSON fetch가 차단될 수 있습니다.
VS Code의 **Open with Live Server** 또는 GitHub Pages에서 실행하세요.

## 지도 복원 버전
이번 버전은 초기 프리뷰에서 예쁘게 보였던 지도 방식으로 되돌렸습니다.

- D3.js 사용
- `d3.geoMercator().fitExtent(...)`
- `d3.geoPath(...)`
- 초기 버전과 동일한 서울 25개 자치구 GeoJSON 소스 사용

이전 로컬 지도 버전에서 사용한 수동 변환/추출 지도 파일은 제거했습니다.

## v9 왼쪽 패널 내부 스크롤 구조
이번 버전은 왼쪽 패널 내부에 `.sidebar-scroll` 래퍼를 추가했습니다.

구조:
- `.sidebar` = 지도와 동일한 높이의 고정 박스
- `.sidebar-scroll` = 실제 스크롤 영역

따라서 데스크톱에서 패널 크기는 그대로 유지되고,
오른쪽 안쪽 스크롤바를 드래그하거나 마우스 휠로 내려서
아래 세부조건까지 확인할 수 있습니다.

모바일/태블릿에서는 기존처럼 페이지 전체가 스크롤됩니다.
